# VELORA – Online Fashion Store (HCI CA3)

HTML + CSS build of our Figma mobile app prototype. Ten screens linked with pure CSS routing (`:target`) — no JavaScript framework.

## Run
Open `index.html` in Chrome or Edge. Each screen has its own URL hash, e.g. `index.html#home`.

## Screens
Onboarding → Sign In → Home → Product Details → My Bag → Checkout → Order Placed, plus the Menu drawer, Android Home (launcher) and Recent Apps. The Android bar at the bottom works: ◁ Back, ○ Home, □ Recent Apps.
